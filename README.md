# Math & Physics AI Tutor — MVP

A browser-based prototype for personalized mathematics and physics practice, aimed at pre-university students aged 15–18.

## Try it

Open [index.html](./index.html) in a modern browser. The prototype requires no installation, server, account, or API key.

## Features

- Mathematics and physics practice exercises
- Deterministic answer checking and selected diagnostic feedback
- Hints and adaptive exercise selection
- Skill mastery estimates and local practice history
- Teacher dashboard for reviewing demonstration progress

## Important limitations

This is an **educational prototype**, not yet an AI-powered multi-student service. It runs entirely in the browser; its feedback is rule-based, and its progress data is stored locally on the device rather than in a shared database. Do not use it to collect real students' personal information or for consequential grading.

## Next milestones

1. Test the correctness of exercises, error diagnoses, and mastery updates.
2. Build a secure backend with individual accounts and teacher-managed classes.
3. Add symbolic mathematics verification (e.g. SymPy) and structured physics/units checking.
4. Integrate an AI tutor for Socratic hints and explanation of student reasoning.
5. Add appropriate authentication, privacy protections, consent/notice flows and deployment safeguards before use with minors.

## Hosting

The repository is currently public. GitHub Pages can host this **static demonstration**, but it must not be mistaken for a secure student platform. GitHub Pages deployment must be enabled separately under **Settings → Pages**.
